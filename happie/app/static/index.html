Koppel je Albert Heijn-account

Eenmalig. Daarna blijft HAppie zelf ingelogd.

  1. Eenmalig: sleep deze knop naar je bladwijzerbalk: HAppie-koppelen (geen balk te zien? Ctrl+Shift+B)
  2. , maar log nog niet in.
  3. Klik op de AH-pagina eerst op HAppie-koppelen in je bladwijzerbalk. Er verschijnt een blauwe balk.
  4. Log nu in. HAppie pakt de code zelf op en koppelt je account. Het AH-tabblad sluit, of gaat zelf door naar HAppie.

Wacht op de code uit het AH-tabblad…

Lukt het niet? Zo vind je de code met F12
  1. Open een computerbrowser, druk op F12 en ga naar het tabblad Netwerk. Zet Log behouden (Preserve log) aan.
  2. Open de AH-loginpagina in datzelfde tabblad en log in.
  3. Na het inloggen blijf je op een lege pagina staan. Zoek in het Netwerk-tabblad met Ctrl+F (zoekt ook in de antwoorden) naar login-exit. Die tekst staat in het verzoek ingelogd. Kopieer het stuk appie://login-exit?code=….
  4. Plak het hierboven. De code is maar een paar minuten geldig.
